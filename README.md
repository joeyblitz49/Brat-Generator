# Brat Generator

Type some words and get a square in the style of the Charli XCX *Brat* covers: lowercase, narrow letters, every line stretched edge to edge, starting in the top left.

## Features

- Fixed text size that only shrinks when you type more than fits
- Separate background and text colors, with quick presets
- Sliders for blur, letter narrowness, line spacing and text size
- Download the result as a 1080x1080 PNG, or copy it to your clipboard

## Use it

Open `index.html` in any browser. Nothing to install, and it works offline.

## Windows app (optional)

1. Download this repo and unzip it.
2. Double-click `install.bat`.
3. A "Brat Generator" shortcut is added to your Desktop and Start menu. It opens the generator in its own window using Microsoft Edge or Google Chrome.

To uninstall, delete the two shortcuts and the `%LOCALAPPDATA%\BratGenerator` folder.
